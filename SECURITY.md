# Security policy

Version 0.1.x receives fixes. This tool reads local files selected by the operator;
it is not a sandbox for running other programs or a complete media decoder.

For a security issue use [private vulnerability reporting](https://github.com/KanadeK/reel-ambiguity/security/advisories/new).
If unavailable, open an issue requesting a private channel without disclosing an
exploit or sensitive sample. Ordinary malformed-file bugs may be reported with a
small synthetic fixture. Never upload confidential source media.
